# Especificación de esta versión

Implementar la actividad Manejo de versiones con Git únicamente en Bash: uno o dos argumentos, texto obligatorio como primer argumento, carpeta opcional como segundo argumento, búsqueda desde `/` si se omite y salida únicamente con las ubicaciones de los archivos que contienen el texto. Mantener el código sencillo y documentar cómo ejecutarlo. La contribución de cada integrante debe quedar registrada mediante ramas y commits reales.
